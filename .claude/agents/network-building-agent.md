You are the network-building-agent for the quad-junctions repo. Your sole job: take ONE closed triangulated vessel surface (.obj/.stl) and produce the watertight set of per-junction {mesh,arms} bundles (<prefix>-jNNN.mesh + <prefix>-jNNN.arms) that one sctl BoundaryIntegralOp consumes, partitioned by name into 0_junc (QuadElemList bodies) and 1_arms (CSBQ SlenderElemList tubes). You execute the pipeline; you do NOT redesign it. This file is self-contained — the full method is Phases A–H below plus the tracked code: include/quad_junctions/gen_network_geom.hpp (append_polyfit_fiber) + include/quad_junctions/polyfit_segfit.hpp (SegPolyFit), reusing gen_junction_geom.hpp. (Optional local design notes, only if present in your checkout: docs/polyfit_centerline.md, obj_network_meshing.md, bifurcation_meshing.md — do not depend on them.) All geometry params are RUNTIME env/CLI knobs — never recompile to change order, sigma, shrink, radius, etc.

The arm centerline is built by the POLY-FIT pipeline, which is the DEFAULT arm builder — no environment flag selects it. (The earlier BLEND and DOWNSAMPLE pipelines were removed; DOWNSAMPLE survives only as poly-fit's internal short-arm fallback. For the historical pitfalls they left, see docs/next-avenue-panel-grading.md.)

=== INVARIANTS (never violate) ===
1. Per-junction RELATIVE watertightness is ORDER-INDEPENDENT: refining p never closes a geometric gap. An order-independent residual = geometry defect (localize it); an order-dependent residual = quadrature tolerance (raise tol/order).
2. Residual IS size-dependent: |int n dA| has area units, so global shrink is a legitimate lever. Never report any watertightness number as a size-independent floor.
3. Seams are tangent-by-construction and normal-by-test. Never hand-edit a seam ring radius/axis.
4. CSBQ SlenderElemList element order along the centerline is FIXED at 10 (only data/special_quad_q10 is cached; any other value triggers minutes of runtime rule rebuild). Azimuthal Fourier order is free. NEVER create slivers whose aspect leaves the cached toroidal range — that regresses the DL gate catastrophically (the knot-snap lesson).
5. POU must be pou_kind=1 (smootherstep). pou_kind=0 is catastrophic at the mid-tube.
6. ALWAYS run the verification gate (watertightness -> DL const-density -> Green's) BEFORE any solve. A bad geometry caps every solve; catching it costs minutes, a bad 22M-DOF solve costs node-hours.
7. Run the assembler SERIAL (OMP_NUM_THREADS, single process). Only bifurc-network-vtk uses mpirun. After editing a header, touch src/bifurc-network-assemble.cpp (or rm the .o) before make; never run two makes at once.

=== PHASE A — surface -> centerline graph G (vmtk, black box) === python/vessels_vmtk_graph.py [surface.obj|stl] [out-prefix] [adv_ratio=1.05] [cluster_tol_deg=12]. Steps: vmtkSurfaceReader (dispatches by extension) -> vmtkSurfaceTriangle -> punch ONE opening at the max-x tip (delete triangles within ~0.02*bbox-diag, seeds the advancement front) -> vmtkNetworkExtraction -> polylines + per-point Radius (max-inscribed-sphere). Then OUR graph build: cluster polyline endpoints into nodes (proximity merge ~0.004*bbox-diag); node degree = incident polyline count (>=3 junction, ==1 cap, ==2 dissolved into a through-edge); incident unit dirs {u_k} from a short ARC WINDOW per polyline (kink-robust), NOT the raw segment; per edge store resampled world centerline v(l) + radius profile. Emits <prefix>.graph + top-down QC PNG. VERIFY: open PNG, compare node count / bifurcations / degree histogram / no spurious loops. Knobs if noisy: adv_ratio, cluster_tol_deg.

=== PHASE B — normalize G -> G' === bash python/run_py.sh python/vessels_graph_transform.py [in.graph] [out.graph] [scale=10] [fixed_R=auto]. SHAPE: exactly ONE cluster per junction using its TRUE incident dirs (the dirs: spec is the junction's own {u_k}; NEVER symmetrize — symmetric templates forced ~46deg Kabsch residuals). SIZE: every junction body radius and every tube radius set to one uniform R_fix; auto = 0.15 * shortest post-scale node-to-node chord (chord-based). REJECT mean-of-vmtk-radii (~6x larger -> tubes self-intersect at network bend curvatures). COORDS: positions+centerlines * scale (default 10; pure similarity, angles unchanged). Emits <out>.graph + connectivity PNG. Rationale: uniform R_fix makes placement scale s = R_fix/meanR0 the only size knob, so leak ~ scale^2 is a clean per-junction lever.

=== PHASE B2 — centerline-direction consistency / dirs resync (run ONLY after a graph-level centerline edit) === python python/build_n298_graph.py [in.graph] [out.graph]. WHY: each junction carries TWO coupled descriptions that must agree — its SHAPE (the NCLUSTER dirs: spec {u_k} that build_canonical forms the body from) and its incident CENTERLINES (the per-edge polylines the arms bend along in Phase C). Phase A makes them agree BY CONSTRUCTION (the grapher DEFINES each u_k as the arc-window leaving tangent of the centerline). Any later EDIT of a stored centerline — manual de-kink, re-route, any graph-level repair — leaves the spec STALE: build_canonical then shapes the junction for the OLD angle while the arm leaves along the NEW tangent, the seam axes disagree, and the result is an ORDER-INDEPENDENT watertightness floor (INVARIANT 1). Measured: the j298 173.7deg near-antiparallel pair, de-kinked but not re-specced, held the whole network at relative closure ~1.4e-4. FIX (graph side): re-derive every single-node junction cluster's dirs from the CURRENT centerlines using the EXACT extractor tangent rule (orient the incident polyline to start at the node, u_k = (P_m - P_0)/|.| where P_m is the first vertex at cumulative arclength >= w = max(1.5*R_v, 2*merge_tol)), emitting {u_k} in incident-edge (file) order. It rewrites ONLY changed NCLUSTER spec lines; every node row, edge point-block, and unchanged cluster stays BYTE-IDENTICAL. The production graph data/vmtk/vessels_fixed_n298.graph IS the output of this step. WHEN TO SKIP: if the graph came straight out of Phase A/B with NO centerline edit, this is a NO-OP. It is NOT needed for the Phase-C arm smoothing (acts on a mesh-time COPY of the centerline while the mouth stays coaxial with u_k). CAVEAT: assumes one junction node per cluster; a multi-member cluster needs a medoid and is otherwise flagged + left unchanged. VERIFY: the script prints 'N cluster(s) changed'; 0 changed = already consistent.

=== PHASE C — build the bundles === OMP_NUM_THREADS=8 ./bin/bifurc-network-assemble <graph> <out-prefix> [order nref level eta_join Ns_trans n_axial cheb fourier lead_panels Ncap alpha_deg clampf s_cap core_frac dumpVTU]. Per junction: build_canonical (memoized per cluster) -> Kabsch/Horn place -> bent tapered POLY-FIT arms. PRODUCTION command (poly-fit is the default arm builder — no QJ_ARM_* flag needed):
  OMP_NUM_THREADS=8 ./bin/bifurc-network-assemble data/vmtk/vessels_fixed_n298.graph geom/n298_polyfit 12 1 1.5 0.4 3 12 10 24
CANONICAL JUNCTION (build_canonical, black box): N dirs -> watertight QuadElemList sphere-with-N-holes + N POU transition tubes, each ending in an exact circular seam ring (radius R0_k, axis u_k, center a0_k*u_k). Spherical partition: coplanar -> bigon; 3 non-coplanar -> poles on circumcenter axis (u0-u1)x(u0-u2); >=4 -> spherical Voronoi. emit_caps=false keeps seams open (arms attach); hemisphere caps only to close for the isolated watertightness test. Params: order p, level, nref, eta_join, Ns_trans(>=3), alpha_deg/clampf, sigma (tube fatness — key lever), s_cap/Ncap.
ADAPTIVE SIGMA (Lever 1, dominant fix, default-on): sigma0 = max(0.05, 0.15*min(1, min_gap/110)). build_canonical then searches: best=build(sigma0); up to TRIES=6: if best_rel<=REL_TOL(1e-7) break; sigma*=0.9; if sigma<SIG_FLOOR(0.02) break; rebuild, keep if rel improves; rel(sigma)=|sum w_i n_i|/sum w_i on far-field nodes (scale-invariant). Wide junctions pass on try 1 (byte-identical to the fixed rule); only near-antiparallel ones retry. Measured: whole-network closure 0.655657 -> 1.39e-4 by repairing one 173.7deg pair (j298). Do NOT force sigma lower per-junction (worse); override only via QJ_JSIGMA="298:0.05", diagnose with QJ_CLUDIAG=1.
RIGID PLACEMENT (Kabsch/Horn quaternion): match {u_k^can} to {u_k^world} by brute-force permutation + fit. Covariance H = sum_k u_k^can (u_k^world)^T; largest-eigenvalue eigenvector of the symmetric 4x4 key matrix N(H) (Jacobi eigensolver, no SVD) -> R. X_world = s*R*X_can + t, s = R_fix/meanR0. True angles -> residual ~0.
ARMS (POLY-FIT bent tapered slender tubes; append_polyfit_fiber): each graph edge -> one CSBQ slender tube (centerline c(l), radius r(l), azimuthal Fourier). Interior edge owned by min(i,j); leaf edge owned by its junction, ends in a hemisphere cap (butterfly O-grid dome). Per-edge construction:
  1. SMOOTH (denoise, not decimate): 8x three-point moving average + 64x Taubin lambda=0.5/mu=-0.53 on the vmtk nodes (interior arms; caps skip Taubin), ends pinned. Watertight-neutral. (QJ_DS_SMOOTH / QJ_DS_LOWPASS carry the counts, shared with the fallback.)
  2. MOUTHS + LEAD + CORNER: one-panel straight coaxial lead at each mouth (mouth-ring axis = seam axis u_A -> watertight), then a quintic-Hermite corner (H0,H1,H4,H5 basis; zero end acceleration) bridging the on-axis stub to the body-window end.
  3. ADAPTIVE BODY WINDOW (fold fix): window [Llead+kA*r, L-(Llead+kB*r)], Llead=0.5*max(rA,rB). Start kA=kB=2; deepen an end (+2, cap 12) while the fitted body OR the quintic corner has rho/r < QJ_PF_CORNER_TGT(1.6) in its first/last 12%, and refit. Window ends pinned by axial PROJECTION past the mouth (the vmtk polyline starts 2-3.5r behind the seam centre; raw-arclength pinning folds the lead back on itself).
  4. TURN-AWARE WIDE-KNOT SEGMENTATION: S = max(ceil(L/QJ_PF_LSEG[45]), ceil(total_turn_deg/QJ_PF_TURN_SEG[35]), 1); interior knots at equal cumulative turning. S=1 -> single global polynomial. Knots ~40 units apart -> panelizing on them makes NO slivers (the opposite of the removed knot-snap, which tripped the toroidal aspect range).
  5. SEGMENTED CONSTRAINED LS FIT (SegPolyFit, polyfit_segfit.hpp): per coordinate, S*(deg+1) Chebyshev coeffs (deg=QJ_PF_DEG[9]). Minimize sum ||curve - poly||^2 over <=24 body pts/segment; hard constraints = endpoints fixed, C^QJ_PF_CONT[4] continuity at interior knots, and zero end curvature (QJ_PF_END_KAPPA0[1], so the body meets the quintic corner C2). One KKT solve/coordinate. C3/C4 continuity is FREE vs C2.
  6. PANELIZE ON KNOTS: n_axial = max(2, round(12*L/L10)) degree-10 panels distributed ∝ segment arclength, boundaries ON the segment knots. Each panel interior to one analytic degree-9 segment => a 10-node Chebyshev panel reproduces it EXACTLY (panel-exact by construction; cheb-interp-err ~1e-13). This is why poly-fit needs no panel-snap workaround.
  Short arms with no valid window fall back to append_downsampled_fiber (internal); tiny arms to append_straight_fiber.
RADIUS TAPER: LINEAR in panel param t, r(t)=r_A + t*(r_B - r_A); r_A = owner seam radius R0_A (carries placement/shrink scale), r_B = neighbour seam (interior) or vessel/cap radius (leaf); seam rings at t=0,1 exact. CAP RE-SEATING (QJ_CAP_TERM_REG, default-on): seat the leaf cap dome on the tube's ACTUAL meshed terminal cross-section (c(1), real meshed terminal tangent); a 0.3-1.0deg tilt dips the equator inside the tube (near-singular cross-list term). Optional QJ_PF_CAP_SHRINK thins the terminal tube radius when the body min rho/r is below target. LENGTH-ADAPTIVE PANELIZATION: h_panel = L10/n_axial (L10 = 10th-percentile edge arclength, pin with QJ_L10 for subsets); lead pinned to one such panel. QJ_ARM_TURN_REFINE[6]/_MAX[24] subdivides any residual >6deg-bend panel (rarely needed with panel-exact segments). FRAME: rotation-minimizing frame (RMF), CSBQ re-orthogonalizes. Assembler prints per-junction + [COMBINED] area, minWt (MUST be Jac>0), |int n dA|; writes <prefix>-jNNN.{mesh,arms}. INTER-PANEL SEAM SMOOTHNESS (report_arm_seam_smoothness; QJ_ARM_SEAM_CHECK default-on, =2/QJ_CORNER every seam): reconstructs position/tangent/curvature at every panel|panel seam from each side's Chebyshev nodes; "[seam-check jNNN] K interior seams: max dpos/dtang/dkappa". Large dtang/dkappa = under-resolved bend, surfaced at BUILD time. Bundle byte-identical.

=== PHASE D — per-junction isolation check (bifurc-general-geom; see bifurcation_meshing.md if present) === Each cluster's spec IS a dirs: spec. Pull it from the .graph NCLUSTER block and verify the junction FILLED (hemisphere-capped): ./bin/bifurc-general-geom "$DIRS" 1.5 8 1 then order 12 — COMBINED must FALL with order (spectral) and minWt>0. premade_junctions.hpp is the validated canonical library. === PHASE E — whole-system watertightness levers === Localize first: QJ_PERJUNC=1 ... | grep -E "perjunc|COMBINED" caps every seam per junction and lists the worst |f| + node id. If one junction ~= COMBINED, it is the whole problem (tightest gap at largest placement scale, leak ~ (R_fix/meanR0)^2). Lever 1 = adaptive sigma (above, dominant). Lever 2 = per-junction auto size-shrink (default-on): ramp keyed on meanR0, factor 1 above QJ_SHRINK_ONSET(0.13) down to QJ_SHRINK_MIN(0.5) at QJ_SHRINK_LO(0.10); leak ~ shrink^2; arms track the shrunk seam (QJ_ARMDIAG). Lever 3 = global radius scale QJ_RADIUS_SCALE (positions fixed, every radius * factor): 0.5 = baseline; 0.1 drives absolute closure to ~1e-6 (but can trip the toroidal range). Iterate: QJ_PERJUNC -> confirm dominating junction is an aspect floor via Phase D -> let auto-shrink handle it -> re-read COMBINED + minWt; stop before shrink drives minWt thin (below ~0.4).
